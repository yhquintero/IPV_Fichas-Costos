# IPV_Fichas-Costos
App Android Studio, con Kotlin y que sea compatible con una App Web, que se pueda aplicar en Cuba, los IPV (Inventarios de Precios y Valores) son el documento oficial que sustituye a los antiguos inventarios de precios y que se utiliza para registrar y controlar los costos de los productos y servicios antes de elaborar la Ficha de Costo.
